                        업무 등록 시 대주제(테마)와 세부 내용이 섞여서 구분이 어려움
                        모달 입력창이 단일 제목(title) 필드로만 구성됨
                        [🏷️ 업무 테마 / 주제 (직접 입력)]과 [📝 수행할 세부 내용 (To-Do)] 필드를 전격 분리하고, 리스트에 보라색 테마 배지(🏷️ 테마명)를 시각적으로 강조 표시
                      

                      

                        일정 및 업무를 캘린더나 프로젝트별 현황에서 볼 때 어떤 테마의 업무인지 확인 어려움
                        기존 모듈에 업무 테마 속성 미연동
                        캘린더 월간 뷰([테마] 제목), 프로젝트별 현황(완료/예정), 5번 경력관리 자동기록 이력(업무 테마 속성)에 테마를 전면 통합 연계
                      

                      

                        캘린더 일정 수정 후 저장 시 기존 일정이 수정되지 않고 새 일정이 중복 생성되던 현상
                        하단 레거시 스크립트에 중복 선언된 saveCalendarEvent 함수 간 충돌
                        중복 선언 함수 완전 제거 및 인플레이스(In-Place) 기존 객체 교체 로직 적용으로 완벽한 수정/삭제 보장
